# אבויויו – חבילת ייחוס ל-Cursor

הקבצים כאן מיועדים לשימוש כ־Design Reference לצורך שדרוג עיצוב של אתר קיים. הם אינם פרויקט React/Next/Vue להעתקה ישירה.

## מקורות

- `Avuyoyo_Design_Language_Dev.pdf`: ספר המותג המקורי, 12 עמודים.
- `tokens.css`: קובץ מקור מדויק שחולץ מקובץ ZIP שהוטמע בתוך ה-PDF.
- `components.css`: סגנונות רכיבים לדוגמה, כפי שסופקו בקובץ ZIP המוטמע.
- `gallery-desktop.html`, `gallery-mobile.html`, `filter-sheet-mobile.html`: הדגמות HTML למראה המיועד. אלו דוגמאות סטטיות, אין להחליף באמצעותן את האפליקציה הקיימת.
- `reference-images/`: תמונות של עמודים נבחרים מתוך ספר המותג, שנועדו לסייע ל-Agent להבין את הפריסה והעיצוב החזותי.
- `illustration-from-demo.svg`: איור SVG שחולץ מהדגמת ה-HTML (אינו בהכרח קובץ המותג/לוגו הרשמי). אם יש קובץ לוגו רשמי – השתמשו בו.

## איך להשתמש

1. חלצו את תוכן ה-ZIP ישירות לתיקייה הראשית של פרויקט האתר (כך שתיווצר `docs/brand/`).
2. ב-Cursor פתחו את הפרויקט הקיים ואת Agent, וצרפו את `docs/brand/Avuyoyo_Design_Language_Dev.pdf` דרך כפתור הצירוף בצ׳אט.
3. הפנו את Agent לקובצי CSS/HTML ולתמונות ב-`docs/brand/`; השתמשו בקובץ `CURSOR_PROMPT.md` כבקשת העבודה הראשונה.
4. התחילו בסקירת הפרויקט ותכנית בלבד. בצעו שינויי קוד בהדרגה לאחר אישור התכנית, עם בדיקות אחרי כל שלב.

## אזהרה הנדסית

אל תדרסו את קובצי ה-CSS של האפליקציה ב-`components.css` ללא סקירה. הקובץ מכיל סלקטורים גלובליים וכללי reset שעלולים לשנות רכיבים קיימים. יש למפות טוקנים ולחלץ רכיבים כך שיתאימו לסטאק ולארכיטקטורה בפועל, תוך שימור זרימות, הרשאות, API ונתונים.
