# DPIA — קטינים, הערות רגשיות, BI מצרפי

טיוטת הנדסה. **לאישור עורך דין / DPO.** לא ייעוץ משפטי.

## עיבוד

- הרשמת בני נוער לקורסים (שם, טלפון, שנת לידה, הורה לקטין).
- הערות מדריך על התנהגות בקורס כולל היבט רגשי/נפשי (`instructor_notes`, `form1/2/3_notes`, `form3_feedback`).
- BI מצרפי לאדמין (מספרי קורסים/השמה) **בלי שמות ובלי הערות**.

## סיכונים

1. דליפת הערות רגשיות (CSV למחשב פרטי, קישור קסם, IDOR).
2. עיבוד מידע על קטינים בלי הסכמת הורה.
3. שיכפול PII למעבד לא מורשה (Apps Script — בוטל).
4. שליחת PII ל-Gemini — אסור; רק תוכן קורס של מדריך.

## בקרות שיושמו בקוד

- שנת לידה + הסכמת הורה אם גיל &lt; 18.
- יידוע סעיף 11 + opt-in שיווקי נפרד.
- SELECT ברירת מחדל בלי הערות; `can_view_sensitive_notes`; CSV בלי הערות כברירת מחדל.
- יומן `view_notes` / `update_notes` / `export_csv`.
- MFA: מנהל באפליקציית TOTP, מדריך ב-SMS; זכירת מכשיר 20 יום; idle 30 דק׳; חסימת `disabled`.
- TTL קישור קסם 14 יום; signed URL לקבצים 60 שנ'.
- `organization_id` nullable לבידוד עתידי.

## החלטה

להמשיך בעיבוד עם הבקרות לעיל, בכפוף לאישור משפטי, DPA מול ספקים, ו-PT לפני עלייה משמעותית.
